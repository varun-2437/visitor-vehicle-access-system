QUERY #1:
-------------------------------------------------------------------------------
User Request:
"1. when the password is entered wrong it does not say the password is wrong it
just refreshes the page"

Modification & Solution Summary:
- Cause: The Axios response interceptor in `frontend/src/api.js` was redirecting
  ANY HTTP 401 response directly to `window.location.href = "/login"`, which
  refreshed the page before the login component could render the error message.
- Fix: Updated `api.js` to exclude `/api/auth/login` from automatic 401 redirects.
- Result: Entering an invalid password now stays on the page and renders a clear
  red alert box: "Incorrect username or password".

-------------------------------------------------------------------------------
QUERY #2:
-------------------------------------------------------------------------------
User Request:
"2. the paste qr option does not make sense as a qr cannot be pasted in text box
make it as a camera feed or a image paste box or as a file selector as input
or add everything if possible"

Modification & Solution Summary:
- Cause: The guard panel only had a basic text input for raw token strings.
- Fix: Upgraded `GuardDashboard.jsx` to support 4 comprehensive QR input methods:
    1) Live Camera Scanner (webcam/mobile camera using html5-qrcode)
    2) Select QR Image File (`.png`, `.jpg`, `.jpeg` image picker decoded via html5-qrcode.scanFile)
    3) Paste Image from Clipboard (Clickable paste zone + `Ctrl+V` / `Cmd+V` global listener)
    4) Manual Token String (UUID string fallback)
- Result: Security guards can scan via camera, upload a saved QR photo, paste a copied image, or type the code.

-------------------------------------------------------------------------------
QUERY #3:
-------------------------------------------------------------------------------
User Request:
"3. in the same page there is no manual entry for a vehicle make sure to
implement it"

Modification & Solution Summary:
- Cause: Walk-in visitors or arriving vehicles without pre-generated QR passes
  could not be registered by the gate guard.
- Fix: Created new backend endpoint `POST /api/qr/manual-entry` and added a
  dedicated form "🚗 Manual Vehicle Entry / Register" on `GuardDashboard.jsx`.
- Result: Guards can type Vehicle Number, Visitor Name, Flat Number (optional),
  and Purpose to immediately log vehicle Entry or Exit at the gate.

-------------------------------------------------------------------------------
QUERY #4:
-------------------------------------------------------------------------------
User Request:
"4. in the same guard page there should be an option to see the list of vehicles
that have been approved nd that was created today and the vehicles that have
been entered and exited."

Modification & Solution Summary:
- Cause: Guards had no visibility into expected visitors or today's gate traffic.
- Fix: Added endpoints `GET /api/qr/today-passes` and `GET /api/qr/today-logs`,
  and added view tabs on `GuardDashboard.jsx`:
    - 🎫 Today's Approved Visitor Passes
    - 🚗 Today's Entry / Exit Activity Logs
- Result: Tables auto-refresh in real time whenever a QR code is scanned or a
  manual entry is submitted.

QUERY #5:
-------------------------------------------------------------------------------
User Request:
"5. the resident creating a pass has three steps 'pass created not inside' ->
after entering into the campus the Vehicle status should be 'in the campus' ->
'Vehicle exitted' the campus."

Modification & Solution Summary:
- Cause: Pass status previously used generic terms (`approved`, `used`).
- Fix: Updated `PassStatus` enum in `backend/models.py` and status transitions
  in `backend/routes/qr.py` to enforce the 3-stage vehicle lifecycle:
    Stage 1: `not_inside`  --> "🟡 Pass Created (Not Inside)" (On pass creation)
    Stage 2: `in_campus`   --> "🟢 In Campus" (On guard Entry scan/manual log)
    Stage 3: `exited`      --> "🔵 Vehicle Exited Campus" (On guard Exit scan/manual log)
- Result: Both Resident and Guard dashboards render live stage badges matching
  this exact 3-step lifecycle.
