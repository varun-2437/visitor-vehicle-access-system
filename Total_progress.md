# Total Progress Summary
**Smart Visitor Vehicle Access System — 23CCE381 Open Lab I**
*Last Updated: 2026-07-27*

---

The Smart Visitor Vehicle Access System project was initiated as a camera-based solution for automating vehicle entry in gated communities by reading Indian license plates (ANPR) and sending digital approval requests to residents. The project began with environment setup on a MacBook Air (Apple Silicon, Python 3.9, virtual environment) and repository scaffolding on GitHub with a dedicated `testing` branch for all experimental work. The ANPR research phase involved testing five different detection and OCR pipelines: **V1** used OpenCV contour detection paired with Tesseract and EasyOCR, achieving 50% detection on 4 test images; **V2** tried generic YOLOv8 which completely failed as it detects vehicles, not plates; **V3** attempted PaddleOCR which crashed due to API incompatibility in newer versions. The breakthrough came with **V4**, where the `sanchit2843/Indian_LPR` repository was integrated — a PyTorch-based pipeline trained on 21,000+ Indian plates using FCOS (object detection), HRNet (semantic segmentation), and LPRNet (OCR). This required patching five NumPy 2.0 incompatibilities in the source code. FCOS achieved **100% plate detection** across all test images, compared to 50% for contour methods. **V5** combined FCOS detection with all three OCR engines (LPRNet, Tesseract, EasyOCR) in a hybrid approach, confirming that no single OCR engine is universally best and a multi-engine consensus strategy is needed. A unified benchmark script (`scripts/test_all_models.py`) was built to run all pipelines simultaneously and output a comparison table, along with a Windows-compatible variant with CUDA GPU support. The three pretrained model weights (`best_od.pth`, `best_lprnet.pth`, `best_semantic.pth`, totalling ~35MB) were committed directly to the repository for a self-contained setup. The tech stack for the full system was finalized as **FastAPI** (backend), **React + Vite** (frontend with three panels: Guard, Resident, Admin), **SQLite** with SQLAlchemy (database), and **WebSockets** for real-time resident notifications. Comprehensive documentation was maintained throughout in `progress.md`. The core AI engine (plate detection and OCR) is fully working and benchmarked; the remaining work is building the backend API, database, frontend UI, and camera integration.
